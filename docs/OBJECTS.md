# Object classes and event kinds

What the level data's object classes and animation events are in the game, from the code that
loads and runs them ([DISC.md](DISC.md) gives their formats). Everything here is read from this
project's decompiled code: a role is named only where the code shows it, otherwise the row
describes what the code does, and inference is marked so. Function names are this project's
readable names (`include/names.h`).

## Object classes

A level's objects name their class by an s16 index into the 149 entries at 0x247448; 0x01 to
0x91 are classes, each with a parent (`config/us/classes.tsv`). 56 have their own load method
(descriptor +0x38); most of those call their parent's and then resolve a few linked objects by
fixed id, and 24 read data of their own from the level (02, 03, 39, 50, 53, 60, 63, 65, 6C, 6E,
73, 74, 78, 79, 7B, 7D, 7E, 82, 83, 86, 88, 8A, 8B, 8E).

## Event kinds

An animation's event lists (DISC.md, "Events") hold events of an s8 kind, 0x00 to 0x3B.
Stream layout of every event (ReadAnimationEvents, func_0012BC38): s8 kind; then, in the timed list only, an s16 time in 1/60 s ticks; then the payload below. "Rev" = the player runs backwards (speed < 0, event in timed list): kinds 9/10, 12/13, 14/15, 17/18, 19/20 invert their on/off. Names of called functions are this repository's readable names (include/names.h). Role words marked (inf) are inference.
